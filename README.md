# 🎭 LarpTok

A mobile-first LARP video/social community MVP powered by GitHub and Supabase.

## Current MVP

- Supabase email/password authentication
- User profiles created automatically on signup
- For You / Following / Latest feeds
- Text, image URL, and video URL posts
- Likes
- Comments
- Follows
- Responsive mobile-first UI
- Basic Row Level Security policies

## Stack

- HTML, CSS, JavaScript
- Supabase Auth + PostgreSQL
- GitHub Pages-ready static frontend

## Supabase setup

The database schema is already applied to the connected Supabase project. The frontend uses the project's public publishable key. Never put a Supabase service-role/secret key in this repository.

## GitHub Pages

1. Open **Settings → Pages** in the repository.
2. Choose **Deploy from a branch**.
3. Select `main` and `/ (root)`.
4. Save.

After GitHub finishes deploying, the site will be available at the repository's GitHub Pages URL.
